# Glossaire

## Présentation

Les termes sont classés par ordre alphabétique. Chaque définition renvoie à la rubrique qui l’explique en détail.

## Termes

| Terme | Signification |
| ----- | ------------- |
| **Agence** | Une unité organisationnelle, comme une succursale ou une région, qui regroupe des utilisateurs, des dépôts et des ressources. Voir [Gérer les agences](../import-and-data-setup/manage-agencies.md). |
| **Application mobile** | L’application TourSolver Mobile, avec laquelle vous partagez les tournées pour que les chauffeurs les effectuent. Voir [Partager une tournée avec l'application mobile](../operations-and-route-management/share-a-tour-with-the-mobile-app.md). |
| **Clé d’API** | La clé secrète qu’un système externe utilise pour appeler l’API TourSolver. Voir [19. Où trouver ma clé API et la documentation de l’API ?](../faq/where-can-i-find-my-api-key-and-the-api-documentation.md). |
| **Communication client** | Les SMS et emails que TourSolver envoie à vos clients avant, pendant et après une visite. Voir [Communication client](../customer-communication/README.md). |
| **Compte d’essai** | Un compte gratuit pour tester TourSolver avec un nombre limité de chauffeurs, d’optimisations et de livraisons. Voir [Processus d'inscription](../getting-started/signup-process.md). |
| **Contrainte** | Une règle qu’une ressource ou une visite doit respecter pendant l’optimisation, comme les horaires de travail, la capacité ou les compétences. Voir [Modifier une ressource et les contraintes associées](../resource-and-vehicle-management/modifying-a-resource-and-associated-constraints.md). |
| **Créneau horaire** | La période de la journée pendant laquelle une visite peut avoir lieu. Voir [14. Comment puis-je prioriser certains créneaux horaires ?](../faq/how-can-i-prioritize-certain-time-slots.md). |
| **Dépôt** | Le lieu où les tournées commencent et se terminent, et où les ressources peuvent recharger. Voir [Créer un dépôt](../import-and-data-setup/create-a-depot.md). |
| **Fréquence** | Le nombre de fois qu’un client doit être visité sur une période de plusieurs semaines. Voir [Optimiser sur plusieurs semaines avec des fréquences](../operations-and-route-management/optimize-over-several-weeks-with-frequencies.md). |
| **Géocodage** | La conversion d’une adresse en coordonnées sur la carte. Voir [Corriger les adresses non géocodées](../import-and-data-setup/fix-addresses-that-are-not-geocoded.md) et [12. Comment optimiser le géocodage dans TourSolver ?](../faq/how-do-i-optimize-geocoding-in-toursolver.md). |
| **Géolocalisation** | La position en temps réel de vos livreurs, envoyée depuis l’application mobile. Voir [Comment géolocaliser mes livreurs](../operations-and-route-management/how-do-i-geolocate-my-delivery-people.md). |
| **Livraison** | Une visite à l’adresse d’un client que vous importez et planifiez dans une tournée. Voir [Import des livraisons](../import-and-data-setup/import-of-deliveries.md). |
| **Modèle de document** | Un modèle utilisé pour générer des documents, comme des feuilles de route, à partir de vos tournées. Voir [10. Que sont les modèles de documents dans TourSolver ?](../faq/what-are-document-templates-in-toursolver.md). |
| **Optimisation** | Le calcul qui construit les meilleures tournées à partir de vos livraisons, ressources et contraintes. Voir [Optimiser vos livraisons](../operations-and-route-management/optimize-your-deliveries.md) et [Configurer les paramètres d’optimisation](../simulation/simulation-optimization-settings.md). |
| **Pause** | Un arrêt dans une tournée, comme une pause déjeuner ou une pause légale de conduite. Voir [Ajouter une pause](../simulation/simulation-deliveries-add-break.md) et [25. Comment ajouter des pauses déjeuner et des pauses de conduite réglementaires ?](../faq/how-do-i-add-lunch-breaks-and-legal-driving-breaks.md). |
| **Quantité** | Une mesure de capacité d’un véhicule, comme le poids, le volume ou le nombre de palettes. Voir [Renommer une quantité d'un véhicule](../resource-and-vehicle-management/rename-a-quantity-of-a-vehicle.md). |
| **Rechargement** | Un retour au dépôt pendant la tournée pour charger ou décharger des marchandises. Voir [Planifier les rechargements, le multi-dépôt et les tournées avec nuitées](../operations-and-route-management/plan-reloads-multi-depot-and-overnight-routes.md). |
| **Rendez-vous à replanifier** | Une visite avec un horaire convenu que vous ajoutez de nouveau à une simulation pour qu’elle soit replanifiée. Voir [Ajouter des rendez-vous à replanifier](../simulation/simulation-deliveries-add-appointments-to-reschedule.md). |
| **Ressource** | Un chauffeur ou un technicien, avec le véhicule et les contraintes utilisés pour planifier ses tournées. Voir [Création d'une ressource](../resource-and-vehicle-management/creating-a-resource.md). |
| **Sectorisation** | L’affectation de secteurs aux ressources, pour que chacune travaille dans sa propre zone. Voir [Affecter des secteurs (sectorisation)](../operations-and-route-management/assign-territories-sectorization.md). |
| **Simulation** | Le résultat d’une optimisation, que vous vérifiez et ajustez avant d’utiliser les tournées. Voir [Simulation](../simulation/simulation.md). |
| **Tableau de bord de suivi** | Un tableau de bord qui suit l’avancement de vos tournées et de vos visites. Voir [Créer un tableau de bord de suivi](../operations-and-route-management/create-a-monitoring-dashboard.md). |
| **Temps d’attente** | Le temps pendant lequel une ressource attend sur une visite avant l’ouverture de son créneau. Voir [13. Pourquoi ai-je du temps d'attente dans mon plan de tournée ?](../faq/why-do-i-have-waiting-time-in-my-route-plan.md). |
| **Tournée** | La liste ordonnée des visites qu’une ressource effectue pendant une journée. Voir [Gérer les tournées](../simulation/simulation-routes.md). |
| **Verrouiller** | Conserver une livraison ou une tournée telle quelle, pour que la prochaine optimisation ne la modifie pas. Voir [Verrouiller et déverrouiller des livraisons](../simulation/simulation-deliveries-lock-unlock.md) et [Modifier les tournées manuellement : réordonner, verrouiller et annuler](../operations-and-route-management/edit-routes-manually-reorder-lock-and-undo.md). |
| **Visite non planifiée** | Une livraison que l’optimisation n’a pu placer dans aucune tournée. Voir [Diagnostiquer les visites non planifiées et les tournées incohérentes](../operations-and-route-management/diagnose-unplanned-visits-and-inconsistent-routes.md) et [23. Pourquoi aucune visite n’est-elle planifiée après l’optimisation ?](../faq/why-are-no-visits-planned-after-the-optimization.md). |
| **Vitesses variables** | Des vitesses qui changent selon l’heure de la journée, pour refléter le trafic. Voir [Configurer des vitesses variables](../resource-and-vehicle-management/configure-variable-speeds.md). |
| **Zone de transit interdit** | Une zone que les tournées ne doivent pas traverser. Voir [Créer et utiliser des zones de transit interdit](../import-and-data-setup/create-and-use-forbidden-transit-areas.md). |
