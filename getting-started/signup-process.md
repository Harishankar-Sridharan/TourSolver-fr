# Processus d'inscription

## 1. Introduction

Bienvenue sur TourSolver ! Ce guide fournit des instructions claires et étape par étape pour vous inscrire à votre compte TourSolver. En suivant ces étapes, vous créerez rapidement vos identifiants et obtiendrez un accès initial à la plateforme.

## 2. Configuration initiale

La création de votre compte comporte trois étapes principales : la vérification de votre e-mail, la définition des informations de votre profil et la finalisation de la configuration de votre entreprise.

### Configuration requise

TourSolver est conçu pour fonctionner de manière optimale sur les navigateurs Web modernes. L'application a été testée et validée avec les versions suivantes :

* Google Chrome : version 142 et supérieure
* Mozilla Firefox : version 145 et supérieure
* Microsoft Edge : version 142 et supérieure
* Apple Safari : version 26 et supérieure

L'utilisation de l'un des navigateurs ci-dessus garantit les meilleures performances et un accès complet aux fonctionnalités de TourSolver.

### Étapes d'installation/configuration

TourSolver est une solution entièrement basée sur le cloud hébergée sur Microsoft Azure, ne nécessitant aucune installation locale.

## 3. Explication des fonctionnalités avec avantages

Une fois que vous aurez terminé le processus d'inscription, votre compte TourSolver sera prêt.

L'avantage du compte d'essai est qu'il vous permet de tester la plateforme immédiatement. Pendant la période d'essai, vous pouvez explorer la plateforme avec les limites suivantes :

* Jusqu'à 5 conducteurs
* Jusqu'à 5 optimisations d'itinéraires par jour
* Jusqu'à 250 livraisons par optimisation

Ces limites vous permettent de tester des scénarios réels et d'expérimenter la fonctionnalité complète de la plateforme sans configuration complexe.

## 4. Création de votre compte

### Vérifiez votre adresse e-mail

Cette première étape cruciale vérifie votre identité et sécurise votre nouveau compte.

Utilisez l'URL suivante pour commencer le processus d'inscription à TourSolver - [Access/TourSolver](https://cloud.nomadia-app.com/ToursolverCloud)

Si vous avez déjà des identifiants, vous pouvez vous connecter et ignorer ce guide. Si vous n'avez pas de compte, cliquez **Inscrivez-vous maintenant**.

1. Entrez le **Adresse e-mail valide.**
2. Cliquez sur **Envoyer le code de vérification**
3. Tapez le **Code de vérification** reçu dans votre e-mail et cliquez sur **Vérifier le code**

### Définition des détails de votre profil

Vous allez maintenant configurer des informations supplémentaires pour paramétrer votre compte.

1. **Remplir les informations :** Remplissez les informations de votre profil de base, y compris votre nom, votre pays et votre mot de passe pour configurer le compte.
2. **Créez votre mot de passe :** Saisissez le mot de passe choisi. (Au moins une lettre majuscule, au moins une lettre minuscule, un chiffre et un caractère spécial)

⚠ **Avertissement : Exigences du mot de passe :** Votre mot de passe doit être robuste ! Assurez-vous qu'il inclut toutes les exigences énumérées ci-dessus.

3. **Cliquez sur Créer** pour continuer.

<figure><img src="../.gitbook/assets/image (3) (1) (1) (1) (1).png" alt=""><figcaption></figcaption></figure>

<figure><img src="https://github.com/Harishankar-Sridharan/Nomadia-Docs-TourSolver-Self-Service/blob/Docs/.gitbook/assets/GettingStarted-SignupProcess_timestamp_1_to_03%E2%80%931_to_08%20(1).gif" alt=""><figcaption></figcaption></figure>

### Finalisation de la page d'intégration

Après avoir créé votre profil, vous arriverez automatiquement sur la page d'intégration pour saisir les informations nécessaires sur l'entreprise.

1. Entrez le **Nom de l'entreprise, adresse de départ et activité.**

<figure><img src="../.gitbook/assets/image (4) (1) (1) (1).png" alt=""><figcaption></figcaption></figure>

<figure><img src="https://github.com/Harishankar-Sridharan/Nomadia-Docs-TourSolver-Self-Service/blob/Docs/.gitbook/assets/GettingStarted-SignupProcess_timestamp_2_to_08%E2%80%932_to_23.gif" alt=""><figcaption></figcaption></figure>

2. Passez en revue le **Contrat de l'utilisateur final** et cliquez sur la **Case à cocher**.

<figure><img src="../.gitbook/assets/image (5) (1) (1) (1).png" alt=""><figcaption></figcaption></figure>

3. Cliquez sur **C'est parti**

## 5. Connexion pour la première fois

Pour vous assurer que vos identifiants nouvellement créés fonctionnent correctement, il est recommandé de vous déconnecter immédiatement puis de vous reconnecter.
