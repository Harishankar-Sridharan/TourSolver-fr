# 5. Combien de ressources puis-je créer ?

* Dans le **version d'essai en libre-service de TourSolver**, vous pouvez créer et optimiser jusqu'à **5 ressources**.
* Avec un **abonnement actif**, le nombre de ressources dépend de votre forfait d'abonnement. Vous pouvez consulter les détails de votre abonnement dans votre **compte administrateur** sous **Profil → Mon abonnement**.
