# 3. Combien de temps les optimisations de mes itinéraires sont-elles conservées ?

Chaque optimisation d'itinéraire effectuée dans TourSolver est enregistrée dans une simulation. Les simulations sont ensuite conservées pendant une durée qui variera en fonction du cycle de validation :

* Une simulation qui est **enregistrée mais non validée** est conservée dans TourSolver pendant **deux mois**
* Une simulation qui est **enregistrée puis validée** est conservée dans TourSolver pendant **un an (12 mois)**

Une simulation peut être validée de deux manières :

* Depuis la[ ](https://www.toursolver.com/en/faq/managing-simulations-toursolver)liste des simulations accessible via la page d'accueil de TourSolver
* Depuis la fenêtre des résultats d'optimisation dans la page d'optimisation
