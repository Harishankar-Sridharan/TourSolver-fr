# 16. Comment modifier mon abonnement ?

Vous pouvez mettre à jour votre forfait, la quantité de licences ou les informations de paiement depuis les paramètres d'abonnement.

1. Connectez-vous à votre compte.
2. Accédez à **Paramètres → Abonnement / Facturation**.
3. Cliquez sur **Modifier l'abonnement**.
4. Choisissez ce que vous souhaitez modifier :
   * Mettre à jour le forfait
   * Augmenter ou diminuer les licences/véhicules/utilisateurs
   * Ajuster la quantité de produit
5. Vérifiez le nouveau prix et cliquez sur **Confirmer** pour enregistrer les modifications.
