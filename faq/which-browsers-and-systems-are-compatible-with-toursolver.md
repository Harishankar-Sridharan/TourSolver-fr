# 4. Quels navigateurs et systèmes sont compatibles avec TourSolver ?

TourSolver est compatible avec les éléments suivants :

* **Google Chrome**
* **Mozilla Firefox**
* **Microsoft Edge**
* **Apple Safari**&#x20;

Ci‑dessous une liste des versions de navigateurs qui ont été testées/validées avec TourSolver :

* Google Chrome : version 142 et supérieure
* Mozilla Firefox : version 145 et supérieure
* Microsoft Edge : version 142 et supérieure
* Apple Safari : version 26 et supérieure

Les versions de navigateurs ci‑dessous ne sont pas testées ni compatibles avec TourSolver :

* Microsoft Internet Explorer 9, Microsoft Internet Explorer 10, Microsoft Internet Explorer 11

#### Application mobile TourSolver

* **Android**
* **iOS**

Voici la liste détaillée des versions des systèmes d'exploitation mobiles testées/validées avec TourSolver&#x20;

* Android : entre 8.0 et 15
* iOS 15.5 et supérieur
