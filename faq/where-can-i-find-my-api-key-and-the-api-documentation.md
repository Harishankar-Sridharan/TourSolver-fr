# Où trouver ma clé API et la documentation de l’API ?

Trouvez la documentation de l’API TourSolver et la clé API dont vous avez besoin pour connecter vos applications à TourSolver.

## Avant de commencer

* Connectez-vous à **TourSolver** avec un profil utilisateur qui a accès à la page **Configuration**.

## Aperçu des fonctionnalités

* **Documentation de l’API TourSolver** : décrit les API REST de TourSolver Cloud, pour créer, lancer et lire des optimisations, publier des plans de tournées vers l’application mobile et suivre la réalisation des tournées.
* **Clés API** : authentifient vos applications lorsqu’elles appellent l’API TourSolver.

## Ouvrir la documentation de l’API

1. Ouvrez la [documentation de l’API TourSolver](https://toursolver.readme.io/reference/introduction).
2. Lisez l’**Introduction**, puis sélectionnez le service dont vous avez besoin, par exemple **Optimization**, **Fulfillment**, **Client** ou **User**.

## Trouver votre clé API

1. Accédez à **Configuration**.
2. Sous **Rôles et profils**, cliquez sur **Clés API**.

Pour plus d’informations, voir [Where is the API key?](https://toursolver.readme.io/reference/authentication-2) dans la documentation de l’API.

## Conseils

{% hint style="info" %}
**Une clé par cas d’usage** : créez une clé API pour chaque intégration, afin de pouvoir désactiver ou remplacer une clé sans arrêter les autres.
{% endhint %}

{% hint style="warning" %}
**Gardez votre clé API secrète** : ne communiquez pas votre clé API par e-mail ni dans un ticket de support. Une nouvelle clé ne s’affiche qu’une seule fois : copiez-la immédiatement.
{% endhint %}
