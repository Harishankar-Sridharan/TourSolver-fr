# 6. Comment prioriser le moins de km possible / le plus de clients planifiés ?

Pendant l'optimisation, vous pouvez définir des priorités dans le **Paramètres d'optimisation** sous le **Priorités d'optimisation** onglet. Ajustez les paramètres suivants en fonction de vos objectifs :

* **Réduire les kilomètres** : Faible / Normal / Important
* **Réduire la fenêtre de temps de travail** : Faible / Normal / Important
* **Maximiser le nombre de visites** : Faible / Normal / Important
* **Utiliser le moins de ressources possible** : Faible / Normal / Important

Ces paramètres influencent la manière dont l'algorithme d'optimisation équilibre vos contraintes.\
**Astuce :** Attribuez différents niveaux de priorité à chaque paramètre pour de meilleurs résultats. Définir toutes les contraintes sur « Important » entraîne généralement **ne** pas de résultats optimaux
